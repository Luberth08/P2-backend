PROBLEMA: invalid input value for enum estadoservicio: "tecnico_asignado"

CAUSA: La BD en Render tiene valores antiguos del enum, el código usa nuevos

SOLUCIÓN: Aplicar migración que actualiza el enum + merge de heads

NOTA: Hay múltiples heads, pero se solucionará automáticamente con el merge

═══════════════════════════════════════════════════════════════════════

📋 PASO 1: APLICAR MIGRACIONES EN LOCAL (PRIMERO)

cd "C:\Users\Luberth\Documentos\Avance Academico\7mo Semestre\Sistemas de Informacion II\PRIMER PARCIAL\SOFTWARE\BACKEND-repo"

.venv\Scripts\activate

alembic upgrade head

# Deberías ver algo como:
# INFO  [alembic.runtime.migration] Running upgrade ... -> update_estadoservicio
# INFO  [alembic.runtime.migration] Running upgrade ... -> merge_heads_final

# Verificar que funcionó
alembic current

# Debería mostrar: merge_heads_final (head)

═══════════════════════════════════════════════════════════════════════

📋 PASO 2: SUBIR LAS MIGRACIONES AL REPOSITORIO

git add alembic/versions/update_estadoservicio_enum.py

git add alembic/versions/merge_heads_final.py

git add SOLUCION_ERROR_ENUM_RENDER.md

git add SOLUCION_MULTIPLE_HEADS.md

git commit -m "fix: Merge heads y actualizar enum estadoservicio"

git push origin main

═══════════════════════════════════════════════════════════════════════

📋 PASO 3: APLICAR MIGRACIÓN EN RENDER

Opción A - Desde Render Shell (RECOMENDADO):

1. Ve a tu dashboard de Render
2. Abre tu servicio de Backend
3. Click en "Shell" (arriba a la derecha)
4. Ejecuta:

   cd /opt/render/project/src
   alembic upgrade head

5. Espera a que termine
6. La migración se aplicará en la BD de producción

---

Opción B - Conectarte desde local a Render:

1. Obtén tu "External Database URL" de Render PostgreSQL
2. Actualiza tu .env temporalmente:
   DATABASE_URL=<la URL de Render>
3. Ejecuta:
   alembic upgrade head
4. Restaura tu .env al valor local
